# 年度替わりの引き継ぎチェックリスト

毎年 3 月ごろ（卒業・役職交代の前）に、管理者がこのリストを上から確認してください。
チェックしたら、このファイル自体を PR で更新して記録を残すと次の人が助かります。

## GitHub

- [ ] Organization の Owner に、来年度も在籍する人が **2 人以上**いる
- [ ] 卒業する人を Owner から外した（Member に戻すか、Organization から外す）
- [ ] `members` チームを整理した（卒業生を外し、新入部員を招待）
- [ ] OAuth App（`設計会 編集画面`）が **Organization 所有**になっている
- [ ] ruleset「main を守る」が Active のまま

## Cloudflare

- [ ] アカウントのメンバー（Super Administrator）に、来年度も在籍する人が 2 人以上いる
- [ ] ログイン用メールがサークルの共用メールになっている（個人メールなら変更する）
- [ ] 独自ドメインがある場合、更新日と支払い担当を確認した
- [ ] `sekkeikai-opu.sekkeikai.workers.dev` の URL が開ける（配っているポスターの QR コードの行き先）
- [ ] Web Analytics（アクセス解析）が見られる人が、来年度も在籍している

## Figma（教育プラン）

- [ ] 「設計会」チームの管理者に、**教育認証済み**の在学生が 2 人以上いる
- [ ] 卒業する人の下書き（ドラフト）にあるサークルのファイルを、チームのフォルダへ移した
- [ ] 卒業する人が持ち主のファイルの所有権を、後任に移した
- [ ] 卒業する人をチームから外した（認証切れでチームがロックされるのを防ぐ）

## 共用メール・その他

- [ ] サークルの共用メールのパスワードを、新しい管理者に安全な方法で引き継いだ
- [ ] 入部フォーム（Microsoft Forms）の所有者を後任に移した。フォームの URL が変わったら、編集画面 → サイトの設定 → 入部フォーム・連絡先とリンクの「入部フォーム（Microsoft Forms）の URL」を直した
- [ ] 新しい代表者の名前に更新した（編集画面 → ページ → トップページ → 団体概要）
- [ ] Discord・TimeTree が今も使えるか確認した（編集画面 → サイトの設定 → 入部フォーム・連絡先とリンク）
- [ ] 問い合わせメールが今も使えるか確認した。アドレスを変えたら、Cloudflare の環境変数 `CONTACT_EMAIL` を直した（`docs/production-setup.md` の「問い合わせメール」）
- [ ] トップページの文章（年度、活動内容）が古くなっていないか確認した

## 関連授業（シラバス）

「設計を知る」のページとトップページには、岡山県立大学の関連授業をシラバスへのリンク付きで載せています。

- [ ] 新年度のシラバスが公開されたら、`src/lib/syllabus.ts` の `SYLLABUS_YEAR` を新しい年度にした（PR で）
- [ ] `npm run check:links` で、各授業のページと外部リンクがまだ開けるかを確かめ、無くなった授業や名前が変わった授業を直した
